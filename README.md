# Mechanical Iris Container v1

A compact 3D-printable container featuring a mechanical iris aperture mechanism. Rotating the outer ring opens and closes the interlocking blades smoothly.

## Overview

This project was designed as part of a 3D modeling and mechanical design challenge. The goal was to create a functional print-in-place / low-assembly mechanism that optimizes filament consumption while maintaining tight tolerances for mechanical movement.

### Key Features

* **Mechanical Aperture:** Twist-to-open iris lid driven by integrated guide tracks.
* **Low Filament Usage:** Lightweight design optimized for minimal material consumption.
* **Tight Tolerances:** Engineered with ~0.2mm clearances for smooth sliding action without binding.

## How It Works

1. **Outer Ring:** Serves as the actuator with curved guide tracks.
2. **Iris Blades:** Interlocking blades pivot along designated pin axes to expand or contract the central opening.
3. **Base Frame:** Holds the blade assembly in place while providing a container housing.

## Assembly & Printing Guidelines

* **Material:** PLA or PETG
* **Layer Height:** 0.16mm - 0.20mm (recommended for smooth sliding surfaces)
* **Infill:** 15% - 20%
* **Tolerances:** 0.2mm clearance applied on contacting moving surfaces.
